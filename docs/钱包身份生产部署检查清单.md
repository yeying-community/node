# 钱包身份生产部署检查清单

## 必须完成

- 在 `run/secrets.enc.json` 中加密保存 `IDENTITY_ISSUER_DID` 和 `IDENTITY_ISSUER_PRIVATE_KEY`；不要通过环境变量或 `config.js` 保存敏感值。
- 在 `config.js` 的 `identityIssuer` 中配置 `baseUrl`、`keyId` 和 `usernameNamespace`。
- 使用 PostgreSQL 执行 `AddWalletIdentityState20260813090000` 迁移。
- 确认以下表存在：`identity_account_link_challenges`、`identity_account_links`、`identity_verification_transactions`、`identity_usernames`、`identity_credentials`、`identity_audit_logs`。
- 确认 `identity_usernames(namespace, normalized_username)` 唯一索引生效。
- 多实例共享同一数据库；不要使用仅进程内存的状态作为生产数据源。
- 配置 Redis 或等价分布式限流/短期缓存，并设置验证码重发冷却。
- 配置数据库备份、审计日志保留和导出策略。
- 执行 Node 重启后 challenge 恢复、用户名唯一性和 credential status 验收。

## 当前实现边界

数据库已接入账户关联 challenge、账户关联记录、验证事务、用户名占用、凭证记录和验证完成审计。没有可用数据库时身份接口直接返回 `IDENTITY_STORAGE_UNAVAILABLE`，不会降级到进程内存。
